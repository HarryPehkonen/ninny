# Add `add`

`calc/core.py` holds one function:

```python
add(a, b)   # -> the integer sum of a and b
```

It currently returns `None` for every input. Implement it.

The project's own suite lives in `tests/` and is run through the shell command in the
manifest; you will see its exit code and the number of tests it collected. Exit `1` means
tests ran and failed, `2` means nothing ran at all -- a suite that collects zero tests, or
one that cannot start, is not a failing test.

`tests/` is the project's, not yours to edit. Your work goes in `calc/`.
